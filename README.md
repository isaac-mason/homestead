# homestead

Walk around a Gaussian-splat kitchen. Drawn by [spark-radix](https://github.com/asundqui/radix-test) on three.js, with [crashcat](https://github.com/isaac-mason/crashcat) for the collider and character controller.

```sh
pnpm install
pnpm dev
```

Click to walk: WASD, shift to run, space to jump.

Footstep sounds from makecat. Title set in [Paper Mono](https://github.com/paper-design/paper-mono) (SIL OFL, `assets/fonts/OFL.txt`) with [glyph](https://github.com/pmndrs/glyph).
